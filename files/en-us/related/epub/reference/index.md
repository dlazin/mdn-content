This [EPUB](/en-US/docs/Related/EPUB) reference describes the container files, package metadata and manifest elements, navigation documents, and publication content formats of an EPUB 3 ebook.

- [EPUB structure](/en-US/docs/Related/EPUB/Reference/Structure)
  - : The ZIP archive layout of an EPUB, including the [Open Container Format](/en-US/docs/Related/EPUB/Reference/Structure/OCF), [`mimetype`](/en-US/docs/Related/EPUB/Reference/Structure/mimetype), [`META-INF`](/en-US/docs/Related/EPUB/Reference/Structure/META-INF), [`container.xml`](/en-US/docs/Related/EPUB/Reference/Structure/container.xml), [`encryption.xml`](/en-US/docs/Related/EPUB/Reference/Structure/encryption.xml), and the [content directory](/en-US/docs/Related/EPUB/Reference/Structure/Content).
- [EPUB package file](/en-US/docs/Related/EPUB/Reference/Package)
  - : The XML index declaring bibliographic [metadata](/en-US/docs/Related/EPUB/Reference/Package/Metadata), the file [manifest](/en-US/docs/Related/EPUB/Reference/Package/Manifest), and the reading-order [spine](/en-US/docs/Related/EPUB/Reference/Package/Spine).
- [EPUB navigation document](/en-US/docs/Related/EPUB/Reference/Navigation)
  - : The required XHTML navigation file defining the [table of contents](/en-US/docs/Related/EPUB/Reference/Navigation/TOC), [landmarks](/en-US/docs/Related/EPUB/Reference/Navigation/Landmarks), and [page lists](/en-US/docs/Related/EPUB/Reference/Navigation/Page-list).
- [EPUB publication content](/en-US/docs/Related/EPUB/Reference/Content)
  - : Authoring rules and format support for [XHTML](/en-US/docs/Related/EPUB/Reference/Content/XHTML), [SVG](/en-US/docs/Related/EPUB/Reference/Content/SVG), [CSS](/en-US/docs/Related/EPUB/Reference/Content/CSS), [fonts](/en-US/docs/Related/EPUB/Reference/Content/Fonts), [images](/en-US/docs/Related/EPUB/Reference/Content/Images), [audio and Media Overlays](/en-US/docs/Related/EPUB/Reference/Content/Audio), [video](/en-US/docs/Related/EPUB/Reference/Content/Video), [scripting](/en-US/docs/Related/EPUB/Reference/Content/Scripting), [`epub:type`](/en-US/docs/Related/EPUB/Reference/Content/epub:type), and [core media types](/en-US/docs/Related/EPUB/Reference/Content/Core_media_types).
